# Project Summary
The "Night Garden" project is an immersive web application that offers users a tranquil and engaging experience in a virtual garden. It integrates art, music, and nature, allowing users to explore an animated environment filled with vibrant flowers and soothing soundscapes. The application promotes relaxation and creativity through dynamic themes and interactive elements, facilitating meaningful connections with nature.

# Project Module Description
The application comprises several functional modules:
- **Interactive Flower Animations**: Flowers dynamically respond to user interactions, enhancing engagement.
- **Dynamic Themes**: Daily evolving themes based on time and weather provide a unique experience.
- **Soundscapes**: Immersive audio experiences complement visual elements and adapt to user interactions.
- **Gesture Control**: Users can interact through gestures such as tap, swipe, long-press, circle, and pinch.
- **Growth and Unlock System**: Users progress through levels, unlocking new gestures and features.
- **Breathing Guide**: A guided breathing exercise to promote relaxation.
- **Share Functionality**: Users can capture and share their achievements within the garden.

# File Description Inventory
- **uploads/fd766c3f77091d6afcce2730544e6ea3.jpg**: Visual asset enhancing the user interface.
- **src/pages/Index.tsx**: Theme selection page for users to choose their desired experience.
- **src/pages/Game.tsx**: Main game canvas page where users interact with the garden, featuring sound effects for long presses and explosions.
- **src/components/ParticleCanvas.tsx**: Renders particle effects in the game, differentiating effects based on swipe direction and including pinch gesture functionality.
- **src/lib/themes.ts**: Contains theme configurations with expanded note scales and daily variations.
- **src/lib/collection.ts**: Manages user collection progress and local storage.
- **src/lib/audio-engine.ts**: Handles audio playback using the Web Audio API, supporting an expanded 14-note scale and includes sounds for charging, explosion effects, and continuous swipe music.
- **src/lib/growth-system.ts**: Manages growth and unlock systems for user interactions.
- **src/components/BreathingGuide.tsx**: Provides a breathing guide overlay for relaxation.
- **src/components/ShareCard.tsx**: Allows users to share their achievements.
