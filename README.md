# 星夜花园 (Star Garden)

一个治愈的粒子互动网页小游戏。在四季流转的星空下，通过手势与光影互动，收集属于你的花园记忆。

---

## 在线体验

```bash
cd app/frontend
pnpm install
pnpm dev
```

然后打开浏览器访问 `http://localhost:5173`。

---

## 游戏玩法

### 1. 选择主题

进入游戏后，从四个季节主题中选择你的治愈旅程：

| 主题 | 描述 | 收集物品 |
|------|------|----------|
| **春·樱花夜** | 收集飘落的樱花瓣，编织春天的旋律 | 樱花瓣、花蕊、蝴蝶、露珠、花环、春风、新芽 |
| **夏·萤火海** | 捕捉夏夜的萤火虫，点亮星空 | 萤火虫、海星、贝壳、珊瑚、水母、海浪、椰子 |
| **秋·枫叶谷** | 收集金色枫叶，谱写秋日暖歌 | 枫叶、松果、橡果、蘑菇、南瓜、落日、暖茶 |
| **冬·极光雪** | 收集雪花结晶，唤醒极光之舞 | 雪花、冰晶、极光、雪人、铃铛、星光、暖炉 |

每个主题拥有**独立的等级、XP、解锁手势和彩蛋**，可随时切换体验不同氛围。

### 2. 手势交互（逐步解锁）

通过操作获得经验值升级，解锁更多手势：

| 手势 | 操作方式 | 解锁等级 | 效果 |
|------|----------|----------|------|
| **点触绽放** 👆 | 点击/轻触屏幕 | Lv.0 | 绽放烟花粒子 |
| **流光滑动** ✋ | 滑动屏幕（移动 >5px） | Lv.2 | 留下方向感知光轨（向上/下/左/右效果各异） |
| **蓄力烟花** 💫 | 长按 >500ms 后释放 | Lv.3 | 按住越久烟花越大越华丽（+3~6 XP） |
| **主题爆发** 💥 | 600ms 内 **同位置 30px 内** 三连击 | Lv.4 | 触发主题专属特效（春=樱花雨、夏=萤火爆发、秋=枫叶旋风、冬=冰晶绽放） |
| **星云漩涡** 🌀 | 画圆（半径 >30px，标准差/半径 <35%） | Lv.5 | 创造持续旋转的星云粒子群 |
| **星压缩** ⚡ | 画圆后 **2 秒内** 双指捏合 | Lv.6 | 星云被压缩成高亮能量球 |
| **聚散星辰** 🤏 | 双指捏合 / 双指散开 | Lv.7 | 聚拢或散开粒子 |
| **粒子桥** 🌉 | 一指长按 + 另一指贴上 **500ms** | Lv.8 | 两指间生成发光粒子桥 |

#### 手势详细参数

**三连击判定**（主题爆发）
- 时间窗口：600ms 内连续 3 次
- 距离阈值：每次点击与上次落点距离 < 30px
- 任意点击位置偏移过大或间隔超过 600ms，重置计数

**画圆判定**（星云漩涡）
- 最小半径：30px
- 闭合度：标准差 / 平均半径 < 35%（即圆滑度）
- 最少采样点：15 个

**蓄力烟花**
- 触发延迟：500ms（防止误触）
- 蓄力时间决定烟花规模和粒子数量（可跨 1~6 秒）
- 移动超过 20px 取消蓄力

**画圆+捏合**（星压缩）
- 捏合必须在画圆结束后 **2 秒内**执行
- 捏合中心点必须在圆心 **1.5 倍半径** 内

**粒子桥**
- 第一指需长按 500ms 以上才能与第二指组合触发
- 第二指移动超过 5px 取消桥接判定

#### 彩蛋与奖励

- 快速点击 **5 次**（任意位置，1 秒内间隔）→ 触发流星雨奖励
- 连击成功触发主题爆发时有 **50% 概率** 爆发收集物品粒子
- 满足彩蛋条件时（收集 ≥5 件），额外触发 **Combo 组合特效**

**音频反馈**：每个手势都会触发基于五声音阶的治愈音效。捏合音效为**三音和弦**（根音+三度+五度），点击屏幕不同高度对应不同音高，滑动时音高随手指位置实时变化。

### 3. 升级与成长

- 每次交互获得经验值（点击 +1，滑动 +2，长按 +3~6，画圆 +5，捏合 +3，组合技 +8~10）
- 升级解锁新手势和视觉效果
- **四个主题独立等级**：春/夏/秋/冬各有独立的等级、XP、解锁状态和彩蛋
- 等级效果一览：
  - **Lv.1** — 粒子发光增强
  - **Lv.2** — 解锁滑动光轨 + 安静模式漂浮光球
  - **Lv.3** — 解锁蓄力烟花
  - **Lv.4** — 背景星星闪烁 + 解锁主题爆发
  - **Lv.5** — 解锁星云漩涡 + 滑动残留光痕
  - **Lv.6** — 粒子拖尾加长 + 解锁星压缩
  - **Lv.7** — 解锁聚散星辰 + 长按边缘脉冲光晕
  - **Lv.8** — 极光背景效果 + 解锁粒子桥
  - **Lv.9** — 全屏粒子风暴增强
  - **Lv.10** — 交互回声粒子 + 安静时随机微型爆发

### 4. 环境呼吸粒子

安静 3 秒后，画面进入呼吸模式：
- **ambient 粒子**随正弦波呼吸（大小和透明度周期性变化）
- **主题联动**：
  - 春天：花瓣式飘落，轻微旋转
  - 夏天：萤火虫式闪烁，向上飘动
  - 秋天：落叶式摇摆下落
  - 冬天：雪花式缓慢飘落
- **漂浮光球**：安静时从底部缓慢升起的光球，交互后淡出

### 5. 收集系统

- 每进行 **20次交互**，收集当前主题的一个物品（轮询制，70次可集齐）
- 前 5 个物品直接收集，**最后 2 个需集齐前5个触发彩蛋后解锁**
- 连续快速点击 **5次** 会触发额外流星雨奖励
- 收集数据自动保存到本地

### 5. 呼吸引导

点击顶部 **🧘 按钮** 进入呼吸引导：
- 4 轮呼吸循环（吸气 4秒 → 屏息 4秒 → 呼气 6秒 → 放松 2秒）
- 跟随光圈缩放节奏呼吸
- 完成后获得 **+10 经验值** 奖励

### 7. 隐藏彩蛋

游戏中隐藏着 **10 个彩蛋成就**，等待你发现：

| 彩蛋 | 触发条件 |
|------|----------|
| 🌈 初次光轨 | 第一次滑动 |
| 🎆 超级烟花 | 长按蓄力 3 秒以上 |
| 🌌 星云诞生 | 第一次画圆 |
| 🧘 呼吸大师 | 完成 3 次呼吸引导 |
| 🏆 收藏家 | 累计收集 20 件物品 |
| 🦉 夜行者 | 午夜 0~5 点进入游戏 |
| 🌈 彩虹轨迹 | 累计滑动 50 次 |
| ⭐ 造星者 | 累计创造 10 个星云 |
| 🎑 四季收藏家 | 集齐当前主题前 5 个物品 |
| ⚡ 组合大师 | 累计使用 5 次组合技 |

### 7. 每日变化

- **粒子形状**：每天轮换（圆形 / 星形 / 花朵 / 心形）
- **特别事件**：
  - 周日 —— ✨ 流星雨加倍
  - 每7天 —— 🎁 双倍收集

### 8. 分享成就

点击顶部 **📤 按钮** 生成个人成就卡片，包含等级、收集数、连续天数等数据，可下载图片或直接分享。

## 技术栈

- **React 18 + TypeScript** — 核心框架
- **Vite** — 构建工具
- **Tailwind CSS** — 样式系统
- **HTML5 Canvas** — 粒子渲染引擎（含呼吸效果、等级驱动视觉、组合技特效）
- **Web Audio API** — 程序化音频合成（五声音阶音效、三音和弦、背景旋律）
- **LocalStorage** — 本地存档（主题独立等级、收集、连续天数）
- **shadcn/ui** — UI 组件
