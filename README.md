# 星夜花园 (Star Garden)

一个治愈向的粒子互动网页小游戏。在水彩星空下，通过手势与光影互动，收集属于你的花园记忆。

视觉语言统一为**水彩 / 水墨晕染**：烟花形态按地图绑定，收集物与成就使用手绘感 SVG 图标，不使用系统 emoji 贴纸风格。

---

## 本地运行

```bash
cd app/frontend
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:5173`。

生产构建：

```bash
cd app/frontend
npx vite build
npx vite preview
```

背景图位于 `app/frontend/public/themes/`（本地静态资源，不依赖外网 CDN）。

## 游戏玩法

### 1. 选择地图（8 张）

进入后选择一张地图开始；每个主题**独立存档**（等级、XP、手势解锁、收集、彩蛋）。

| 主题 | 描述 | 收集物（7 种） | 烟花形态 |
|------|------|----------------|----------|
| **春·樱花夜** | 收集飘落的樱花瓣，编织春天的旋律 | 樱花瓣、花蕊、蝴蝶、露珠、花环、春风、新芽 | 花瓣 |
| **夏·萤火海** | 捕捉夏夜的萤火虫，点亮星空 | 萤火虫、海星、贝壳、珊瑚、水母、海浪、椰子 | 光晕 |
| **秋·枫叶谷** | 收集金色枫叶，谱写秋日暖歌 | 枫叶、松果、橡果、蘑菇、南瓜、落日、暖茶 | 枫叶 |
| **冬·极光雪** | 收集雪花结晶，唤醒极光之舞 | 雪花、冰晶、极光、雪人、铃铛、星光、暖炉 | 冰晶 |
| **雨·烟波夜** | 聆听细雨低语，收集烟波中的微光 | 雨丝、灯笼、水泡、小舟、烟岚、青苔、涟漪 | 雨丝 |
| **月·桂花庭** | 在桂香月色中拾取银辉与花影 | 满月、桂花、玉兔、烛火、云纱、新月、银辉 | 月牙 |
| **沙·星漠** | 在星空沙漠中追逐流沙与蜃楼 | 沙丘、仙人掌、星砂、风纹、驼铃、蜃楼、残阳 | 沙粒 |
| **湖·睡莲** | 静看睡莲浮于星湖，拾取镜中倒影 | 睡莲、锦鲤、芦苇、月影、水鸭、湖光、浮萍 | 涟漪 |

### 2. 手势交互（逐步解锁）

通过交互获得经验升级，解锁更多手势：

| 手势 | 操作 | 解锁等级 | 效果 |
|------|------|----------|------|
| **点触绽放** | 点击 / 轻触 | Lv.0 | 绽放主题烟花 |
| **流光滑动** | 滑动（移动 >5px） | Lv.2 | 方向光轨（上/下/左/右效果不同） |
| **蓄力烟花** | 长按 >500ms 后松手 | Lv.3 | 蓄力越久烟花越大（约 +3~6 XP） |
| **主题爆发** | 600ms 内同位置 30px 内三连击 | Lv.4 | 主题专属爆发特效 |
| **星云漩涡** | 画圆（半径 >30px，标准差/半径 <35%） | Lv.5 | 旋转星云粒子群 |
| **星压缩** | 画圆后 2 秒内双指捏合 | Lv.6 | 星云压缩为能量球 |
| **聚散星辰** | 双指捏合 / 散开 | Lv.7 | 聚拢或散开粒子 |
| **粒子桥** | 一指长按后第二指贴上 500ms | Lv.8 | 两指间生成粒子桥 |

#### 关键判定参数（与代码一致）

**三连击（主题爆发）**
- 时间窗口：600ms 内 3 次
- 距离阈值：相邻落点 < 30px

**画圆（星云）**
- 最小半径：30px
- 圆滑度：标准差 / 平均半径 < 35%
- 最少采样点：15

**蓄力烟花**
- 触发延迟：500ms
- 移动超过 20px 取消蓄力

**星压缩**
- 须在画圆结束后 2 秒内捏合
- 捏合中心须在圆心 1.5 倍半径内

**粒子桥**
- 第一指长按 ≥500ms
- 第二指移动超过 5px 取消

#### 额外反馈

- 快速点击 5 次（间隔约 1 秒内）→ 流星雨奖励
- 已收集道具会按概率混入烟花（基础约 20% + 每多一种 +3%，上限约 60%）
- 同一主题集齐 **5 种** 解锁基础 Combo；集齐 **7 种** 解锁终极 Combo
- 音频：五声音阶程序化音效；音高随点击高度变化；捏合为三音和弦

### 3. 升级与成长

经验大致为：点击 +1，滑动 +2，长按约 +3~6，画圆 +5，捏合 +3，组合技 +8~10。

**各主题独立等级**，等级视觉效果：

| 等级 | 效果 |
|------|------|
| Lv.1 | 粒子发光增强 |
| Lv.2 | 滑动光轨 + 安静模式漂浮光球 |
| Lv.3 | 蓄力烟花 |
| Lv.4 | 背景星点 + 主题爆发 |
| Lv.5 | 星云漩涡 + 滑动残留光痕 |
| Lv.6 | 拖尾加长 + 星压缩 |
| Lv.7 | 聚散星辰 + 长按边缘光晕 |
| Lv.8 | 极光背景层 + 粒子桥 |
| Lv.9 | 全屏粒子增强 |
| Lv.10 | 交互回声粒子 + 安静时微型爆发 |

### 4. 环境呼吸粒子

安静约 3 秒后进入呼吸模式：ambient 粒子随正弦波呼吸；形态随地图变化（如春/月偏飘落、夏/湖偏上浮、雨偏下落等）。

### 5. 收集系统

- 交互累计达到间隔时获得 1 件收集物（轮询当前主题列表）
- 进度间隔：前 5 种约 **每 40 次**；后 2 种约 **每 60 次**
- 最后 2 种需先集齐前 5 种并触发「四季收藏家」类彩蛋后解锁
- 数据保存在浏览器 LocalStorage

### 6. 呼吸引导

顶部**呼吸**按钮：

- 4 轮：吸气 4s → 屏息 4s → 呼气 6s → 放松 2s
- 完成后 **+10 XP**

### 7. 隐藏彩蛋（每主题 10 个）

| 彩蛋 | 条件 |
|------|------|
| 初次光轨 | 第一次滑动 |
| 超级烟花 | 长按蓄力 ≥3 秒 |
| 星云诞生 | 第一次画圆 |
| 呼吸大师 | 完成 3 次呼吸引导 |
| 收藏家 | 累计收集 20 件 |
| 夜行者 | 0~5 点进入游戏 |
| 彩虹轨迹 | 累计滑动 50 次 |
| 造星者 | 累计创造 10 个星云 |
| 四季收藏家 | 集齐当前主题前 5 种收集物 |
| 组合大师 | 累计组合技 5 次 |

另有全局**成就页**（水彩图标），统计手势、连击、连续天数等。

### 8. 每日变化

- 烟花轮廓由**地图固定**（不再按日轮换心形/星形等通用形状）
- 特别事件：
  - 周日：流星雨加倍
  - 每 7 天：双倍收集倾向

### 9. 分享与花园

- **分享**：生成成就卡片（等级、收集、连续天数、已解锁手势名），可下载或系统分享
- **花园**：按主题查看收集进度与组合技解锁状态

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- HTML5 Canvas（粒子、手势、道具混入、Combo）
- Web Audio API（五声音阶、和弦、旋律）
- LocalStorage（主题独立成长与收集）
- 水彩 SVG 图标（`CollectibleIcon` / `StyleIcon`）
