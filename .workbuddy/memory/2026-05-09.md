# 2026-05-09

## 星夜花园 (Star Garden) - 三处功能更新

### 1. 收集系统更新
- 修改 Game.tsx 收集逻辑：从固定每天1种道具改为按点击次数轮询全部7种道具
- 每10次交互获得1个道具，70次交互可集齐所有7种（原来需要7天）
- 新增彩蛋 theme_complete（四季收藏家🎑）：当前主题所有道具至少收集过1次时触发
- growth-system.ts HIDDEN_DISCOVERIES 新增 theme_complete 条目
- 去掉了 handleGesture 依赖项中的 dailyVariation.collectibleIndex

### 2. 捏合音效柔和化
- audio-engine.ts 删除刺耳的 playPinchSound 方法（triangle振荡器+倍频，每次touchmove触发新音符）
- 新增 startPinchSound()：sine振荡器+低通滤波器，持续音方式，音色柔和
- 新增 updatePinchSound()：实时更新音高
- 新增 stopPinchSound()：淡出停止，带延时清理，destroy() 中也加入调用
- 捏出(scale>=1)时第二振荡器改为纯五度(freq*1.5)，不再用倍频

### 3. 捏合音频残留 bug 修复
- ParticleCanvas.tsx 接口变更：onPinch 拆分为 onPinchStart/onPinchMove/onPinchEnd 三个回调
- onTouchMove：首次检测捏合时调用 onPinchStart，后续调用 onPinchMove
- onTouchEnd：捏合结束时调用 onPinchEnd → 触发 stopPinchSound()
- 处理单指残留边界：捏合结束后若仍有1指留在屏幕，更新 touchStartRef 使其可正常继续交互
- Game.tsx 对应更新：onPinchStart 调用 startPinchSound，onPinchMove 调用 updatePinchSound，onPinchEnd 调用 stopPinchSound()

构建验证：pnpm install + pnpm build 均成功通过，无类型错误。
