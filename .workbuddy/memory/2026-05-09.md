## 星夜花园 - 长按+滑动bug修复 & 收集进度调整

### 1. 长按+滑动bug修复（ParticleCanvas.tsx）
- 一根手指长按蓄力时，另一根手指滑动导致：大烟花不触发 + 蓄力声音卡住
- 原因：onTouchStart 无脑重置 touchStartRef；onTouchMove 两指时直接 return 误判为捏合
- 新增 longPressTouchIdRef + longPressStartPosRef 独立跟踪长按手指
- onTouchStart：若已有手指在长按(isLongPressingRef)，直接 return 不干扰
- onTouchMove：新增 2指+长按中 分支，找滑动手指处理 swipe 声音和拖尾粒子
- onTouchEnd：检测长按手指离开 → 用 longPressStartPosRef 触发烟花 + onChargeEnd 停音效
- onTouchEnd：非长按手指先离开 → 停 swipe 音 + 恢复长按手指状态

### 2. 收集进度调整（Game.tsx）
- 收集间隔：10次 → 20次（放慢一倍，140次交互集齐7种）
- 最后2个物品(索引5,6)需 theme_complete 彩蛋解锁才可收集
- 解锁前 maxIndex=5 只收集前5种；解锁后 maxIndex=7 全部可收集
- allCollected 检查改为：解锁前只检查前5种 → 避免循环依赖
- 集齐前5种后触发 theme_complete（四季收藏家）→ 解锁后两物品

## 星夜花园 - 声音卡住 & 无法点击 bug 修复

### 声音卡住（竞态条件）
- 连续滑动/快速点击时，charge 声音卡住不停止
- 根因：`clearTimeout` 与定时器回调之间的竞态条件
- 场景：手指在 ~500ms 时离开，`onTouchEnd` 调用 `clearTimeout`，但回调已在事件循环中排队
- 回调执行时 `isLongPressing = true`，`onChargeStart` 启动声音，但 `onTouchEnd` 已 return
- 修复：定时器回调中增加防御检查 `if (longPressTimerRef.current === null) return`
- 已保存为技能 `touch-event-race-condition`

### 无法点击（逻辑 bug）
- 刚进入游戏时快速点击无反应
- 根因：`onTouchEnd` 中 `longPressTouchIdRef !== null` 时直接 return，跳过了 tap 检测
- 修复：区分"确实长按"和"只是设置过定时器"，只有确实长按时才提前 return

构建验证：pnpm build 通过，无类型错误。

## 星夜花园 - 捏合音效和弦化 & 水平滑动粒子修复

### 捏合音效（audio-engine.ts）
- 从单音（1-2个振荡器）改为**三音和弦**（根音+三度+五度）
- 3个 sine 振荡器通过低通滤波器，音色丰富柔和
- 捏合程度（scale）控制基础音高：捏入低音、捏出高音
- 增加琶音 LFO（2Hz 脉冲），让和弦有"呼吸感"的音乐律动
- 整体增益提高到 0.12，三个音符叠加更饱满

### 水平滑动粒子（ParticleCanvas.tsx）
- 根因：水平滑动拖尾用 `lighttrail` 类型（扁椭圆 7.5:1），竖直滑动用 `swipe` 类型（圆形）
- 修复：水平滑动拖尾改为 `type: 'swipe'`，与竖直滑动保持一致圆形
- 旋转速度也改为随机（`(Math.random()-0.5)*0.1`），和竖直滑动一致
